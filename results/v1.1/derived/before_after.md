# Before (v1.0) vs after (v1.1)

Ratios of medians of COLD runs. `Metric` names the primary metric of the row (engine latency = DuckDB profile `latency`, without process start-up); the wall-clock ratio (incl. process start-up: 57 ms VM, 154 ms bare metal, median wall-clock of `SELECT 1`) is given in the `*_wall` columns. v1.1 is given per platform: `vm_*` pools the VM core campaigns (core_v2, core_v2_b), `bm_*` the bare-metal ones (bm_core_a, bm_core_b, bm_core_c, bm_core_d, bm_core_e), each with a hierarchical bootstrap 95 % CI (campaigns, then runs); `*_campaign_range` = ratio in each campaign; `*_consistent` = same direction in every campaign and CI excluding 1; `bm_over_vm` = ratio of the two ratios with a CI from both bootstraps; `both_consistent` = consistent on both platforms, same direction and ≥ 1.05× on both. Files: B vs A (same layouts on both platforms).
